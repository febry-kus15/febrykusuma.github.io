About the developer

What’s in the atlas

Each layer is a GeoJSON file you can swap out with your own project data — masterplan parcels, road hierarchy, catchments, anything exported from QGIS in EPSG:4326.

Base map

Four Mapbox styles — streets, light, dark and satellite — switchable from the map panel.

Project layers

Drop GeoJSON into /data, register it in the layer list, and it appears with a toggle.

Attribute popups

Click any feature to read its attribute table entries in a formatted popup.

Getting started

Run a local server from this folder, then open http://localhost:8000. The map page is where the geospatial work happens; this page is the front door.
